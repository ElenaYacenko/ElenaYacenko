**Дипломный проект: `backspark-lk-automation`**
Комплексный фреймворк для автоматизации тестирования функции передачи показаний в личном кабинете.
- **API:** RestAssured, проверка контрактов и валидации.
- **UI (Web):** Selenide, компонентный подход.
- **Mobile (Android):** Appium, UiAutomator2 (эмулятор и BrowserStack).
- **CI/CD:** Jenkins, Allure TestOps, Jira, Telegram-уведомления.
